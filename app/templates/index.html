Strata Logging Service

Traffic & Sessions

Not configured

Traffic & Sessions uses the same Palo Alto Common Services service account configured above: Client ID + Client Secret + TSG ID. NodeWatch exchanges those credentials for a short-lived OAuth token, then queries firewall traffic logs through the Strata Cloud Manager Log Viewer API.

The log query host is the regional host Strata Cloud Manager uses for Log Viewer. To find yours, open Log Viewer, press F12, and look at the host of the logviewer/firewall_traffic request. Turning this on immediately runs one real read-only traffic query, and NodeWatch saves the integration only if that query succeeds. If Palo Alto refuses the query, the exact response is shown here.

Support

Simple support workflow

If something is slow or fails, use the diagnostics files in the persistent data folder. They contain sanitized API timing and local application records. Integration credentials, access tokens, and authorization headers are excluded.

Normal use should require only one launcher: NodeWatch. There is no .env file to edit and no setup script to rerun after upgrades.
