# Shipped v0.10.42 Windows launcher: recorded behaviour

Recorded 2026-10-23 on GitHub `windows-latest` runners by `.github/workflows/launcher-parity.yml`
(runs 39880580105 and 39881183892), starting `NodeWatch\NodeWatch.exe` from the payload extracted from
`shipped/v0.10.42/NodeWatch-windows-installer.exe`. A rebuilt launcher must reproduce every line below.
The log lines are copied from the run's annotations; the timeline's seconds are not reliable (the first
process query takes about 30 s), so durations come from the log timestamps.
